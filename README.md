# FreeTyperBot

**FreeTyperBot** is a lightweight Windows desktop automation tool designed to make repetitive keyboard and mouse actions easier to perform.

It provides customizable typing automation, hotkeys, configurable delays, and an intuitive interface for creating and controlling automation tasks.

## ✨ Features

* ⌨️ Automated keyboard typing
* 🖱️ Mouse automation
* ⚡ Customizable hotkeys
* ⏱️ Configurable typing and action delays
* 🔄 Start/stop automation controls
* 🎨 Modern desktop interface
* 🖥️ Designed for Windows
* ⚙️ Easy-to-configure automation settings
* 🚀 Lightweight and responsive
* 🔒 Runs locally on your computer

## 🛠️ Installation

### Option 1 — Portable EXE

1. Download `FreeTyperBot.exe` from the latest release.
2. Place it anywhere on your Windows computer.
3. Double-click the executable.
4. Start configuring your automation.

### Option 2 — Installer

If an installer is provided:

1. Download `FreeTyperBot-Setup.exe`.
2. Run the installer.
3. Follow the installation instructions.
4. Launch FreeTyperBot from the Start Menu or desktop shortcut.

## 🚀 Usage

1. Launch **FreeTyperBot**.
2. Configure the text or actions you want to automate.
3. Set the required delay or interval.
4. Configure your preferred hotkey.
5. Start the automation.
6. Use the stop hotkey or stop control whenever you want to terminate the automation.

## ⚙️ Configuration

FreeTyperBot allows you to customize automation behavior according to your requirements.

Typical settings include:

| Setting       | Description                           |
| ------------- | ------------------------------------- |
| Text          | Text to be automatically typed        |
| Delay         | Delay between automated actions       |
| Hotkey        | Shortcut used to control automation   |
| Start/Stop    | Controls the automation process       |
| Mouse Actions | Configures supported mouse automation |
